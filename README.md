# Offline Friend Names

Fixes Gorilla Tag hiding offline friend names.

---

## Installation
1. Ensure you have the latest version of BepInEx 5 installed.
2. Download the latest version from the [Releases](https://github.com/pl2w/OfflineFriendNames/releases/latest) page
3. Move the mod into your plugins folder.
